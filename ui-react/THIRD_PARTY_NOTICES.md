# Third-party frontend assets

The production build contains local copies of these assets:

- Foundation for Sites 6.2.3 CSS, copyright ZURB, licensed under the MIT License.
- Titillium Web, distributed through Fontsource, licensed under the SIL Open Font License 1.1.
- The monitor SVG is derived from Foundation Icons 3, copyright ZURB, licensed under the MIT License.

The Foundation and Fontsource license texts are copied into the generated `public/vendor` directory by `scripts/prepare-local-assets.js` and are included in each production build.
